# EduVoice-Kids
AI-powered voice learning assistant for visually impaired children with multilingual storytelling, alphabet learning, speech recognition, and voice narration.
## Overview

EduVoice Kids is an accessibility-focused educational assistant designed for visually impaired children.

The application enables children to interact using voice commands, listen to educational stories, learn English and Hindi alphabets, and receive audio narration through text-to-speech technology.

## Features

- Voice-based interaction
- Speech-to-text recognition
- English moral stories
- Hindi moral stories
- English alphabet learning
- Hindi alphabet learning
- Text-to-speech narration
- Accessibility-focused design
- Repeat narration functionality

## Technologies Used

- Python
- Streamlit
- Faster-Whisper
- gTTS
- Speech Recognition
- Natural Language Processing
